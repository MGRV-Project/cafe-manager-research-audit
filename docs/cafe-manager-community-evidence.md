# 커뮤니티 근거 노트 (2026-08-04, 다각도 조사용)

아래는 `tvly-dev-*` 키를 통해 호출한 커뮤니티 검색 후, 공식 채용공고/직무 정의와 교차 비교한 근거입니다.

## 핵심 관찰

- 실무 체감에서 드러난 주요 리스크는 **근무시간 폭증·보상 체감 불일치**, **업무 경계 모호성**, **스케줄링 운영 부담** 세 가지가 반복됨.
- 커뮤니티 증언은 표본 규모가 작아 정량화된 일반화에는 한계가 있으나, 채용 공고만으로는 잘 안 보이는 문제를 조기에 탐지하는 데 유효함.

## 출처와 반영 포인트

1. **블라인드: `프랜차이즈 카페 매니저로 일하고 싶습니다`**
   - 링크: https://www.teamblind.com/kr/post/%ED%94%84%EB%9E%9C%EC%B0%A8%EC%9D%B4%EC%A6%88-%EC%B9%B4%ED%8E%98-%EB%A7%A4%EB%8B%88%EC%A0%80%EB%A1%9C-%EC%9D%BC%ED%95%98%EA%B3%A0-%EC%8B%B6%EC%8A%B5%EB%8B%88%EB%8B%A4-dJuMg7Hx
   - 반영: 계약시간 대비 실제 근로시간이 길어지고, 포괄임금제 구조·휴일·초과수당 체감이 부정확할 수 있다는 주장. 아침 오픈 전 업무(준비·청소·보충)로 매니저권역의 물리적 업무 부담을 보여줌.

2. **블라인드: `프랜차이즈 카페 오픈바이저/수퍼바이저`**
   - 링크: https://www.teamblind.com/kr/post/%ED%94%84%EB%9E%9C%EC%B0%A8%EC%9D%B4%EC%A6%88-%EC%B9%B4%ED%8E%98-%EC%98%A4%ED%94%88%EB%B0%94%EC%9D%B4%EC%A0%80%EC%88%98%ED%8D%BC%EB%B0%94%EC%9D%B4%EC%A0%80-KaWvmaLN
   - 반영: 주 40시간 기준이지만 연장/야근 가능, 사무/자질구레한 업무가 누적되어 워라밸이 어려운 운영 구조 언급.

3. **Reddit r/barista: `Difference between a cafe manager and a barista?`**
   - 링크: https://www.reddit.com/r/barista/comments/xeck6d/difference_between_a_cafe_manager_and_a_barista/
   - 반영: 매니저의 기본 과업(스케줄, 유지보수, 커버, 고객 불만 대응, 채용·교육, 인력·매출·재고·은행 관련 운영업무)과 바리스타와의 업무 경계 차이 논의가 존재.

4. **Reddit r/smallbusiness: 직원 스케줄링 운영 토론**
   - 링크: https://www.reddit.com/r/smallbusiness/comments/1ub5vfm/how_do_you_handle_employee_scheduling/
   - 반영: 스케줄링은 “툴”보다 규칙이 선행돼야 하며, 가용성 공유·교체 승인·비용 통제 실패가 반복 문제로 제기됨. 매니저의 운영 책임 범위를 시사.
