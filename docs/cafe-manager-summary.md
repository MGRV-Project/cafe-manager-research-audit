# 카페 매니저는 무슨 일을 하나 — 한 장 요약

> 팀 공유용. 전체 근거·다이어그램은 [감사 조서](cafe-manager-dossier.html) · [리서치 원문](cafe-manager-research.md) 참고.

## 한 줄

카페 매니저는 인력·재고·품질·위생·정산을 통제해 매출·원가·고객·직원 지표로 매장 성과를 개선하는 현장 책임자다. 가장 숙련된 바리스타가 아니라, 사람·상품·공간·돈을 조율하는 역할.

## 핵심 업무 7가지

| 영역 | 한 줄 |
|---|---|
| 매장 운영 | 오픈·마감 점검, 피크타임 인력 배치 |
| 인력 관리 | 채용·스케줄·교육·근태 |
| 제품·품질 | 레시피 기준, 메뉴 개선 |
| 재고·구매 | 발주·검수·폐기 관리 |
| 위생·안전·시설 | 청소기준, 장비 점검 |
| 고객 경험 | 응대, 불만 해결 |
| 손익·행정 | 정산, 원가·인건비 확인 |

## ⚠ 가장 중요한 발견

원 리서치가 국내 근거로 쓴 채용공고 3건 중 **2건이 무효였다.** 노원구·강북구 공고를 PDF 원문으로 직접 대조한 결과:

- **노원구** = 노원구청이 직영하는 관광지 카페의 **임기제 공무원** 채용 (9급 상당, 연봉 2,378만원)
- **강북구** = 강북구청이 운영하는 카페의 **기간제 근로자** 채용 (담당업무 4개 전부 "~보조", 상급 관리자 별도 존재)

→ 둘 다 민간 카페의 정규 매니저가 아니었음. **신뢰 가능한 국내 민간 매니저 채용 표본은 잡코리아 공고 1건뿐**으로 축소.

## 숫자로 보는 벤치마크

- 재료원가율 30% · 인건비율 30% · 임대료율 10% 이내 (35평 이하 카페 기준, 배민외식업광장 공식자료)
- 잡플래닛 이디야 리뷰: 3.4/5.0, 968건, 추천율 62%

## 검증 상태

- research-loop 자동검증: `REVISE` (다각도 렌즈 리뷰 기준)
- 원문 PDF 재검증으로 핵심 오류 1건 정정 완료 (위 노원구·강북구 건)
- 남은 갭: 네이버 카페 사장님 커뮤니티 미접근, 폐기율 실수치 미확보
