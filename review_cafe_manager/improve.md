# 리서치 문서 개정 제안

## 한계 — 폐쇄형 커뮤니티 검증 누락 명시 [closed_platform_ethnography]

'하루는 보통 이렇게 흘러간다' 섹션은 채용공고·BLS·O*NET 같은 공식 문서만으로 재구성됐다. 블라인드, 잡플래닛 리뷰, 네이버 카페 사장님 커뮤니티 등 현직자가 실제 경험을 공유하는 폐쇄형·준폐쇄형 채널은 조사 대상에 없었고 한계 섹션도 이를 언급하지 않는다. 문서화된 직무기술서와 실제 현장 운영 간 괴리는 이런 채널 없이 확인 불가능하므로, 해당 채널을 통한 재조사가 필요하다는 점을 한계에 명시해야 한다.

```markdown
// before
하루 흐름과 권장 KPI는 여러 출처의 공통 과업을 바탕으로 재구성한 분석이며 모든 매장에 동일하게 적용되는 규정이 아니다. 특히 소형 카페에서는 한 사람이 매니저·바리스타·행정을 동시에 맡아 직무 경계 자체가 흐릴 수 있다.
```

```markdown
// after
하루 흐름과 권장 KPI는 여러 출처의 공통 과업을 바탕으로 재구성한 분석이며 모든 매장에 동일하게 적용되는 규정이 아니다. 특히 소형 카페에서는 한 사람이 매니저·바리스타·행정을 동시에 맡아 직무 경계 자체가 흐릴 수 있다. 또한 이 흐름은 채용공고·BLS·O*NET 등 공식 문서만으로 구성했으며, 블라인드·잡플래닛·네이버 카페 사장님 커뮤니티 등 실무자가 실제 경험을 공유하는 폐쇄형·준폐쇄형 채널은 조사 범위에 포함하지 않았다. 해당 채널을 통한 재조사로 문서화된 직무기술서와 현장 운영 간 괴리를 확인해야 한다.
```

## 한계 — 스타벅스 자사콘텐츠 홍보성 리스크 명시 [incentive_integrity]

'바리스타·시프트리더·매니저의 차이' 섹션은 역할 구분의 실증 근거로 스타벅스 공식 채용페이지 문구를 그대로 인용한다(예: 매니저를 '사업 성장을 이끄는 리더'로 서술). 이는 스타벅스가 채용·고용주 브랜딩 목적으로 직접 작성·배포한 자사발행 콘텐츠이며, 검색 상위 노출을 노린 홍보성 서술일 수 있다. 한계 섹션은 '업무가 표준화되어 있다'는 점만 언급할 뿐, 이 자료가 지원자 유인을 위해 역할 범위를 실제보다 매력적으로 포장했을 가능성은 다루지 않는다.

```markdown
// before
스타벅스 자료는 대형 프랜차이즈의 공식 역할 정의이므로 소형 개인 카페보다 업무가 표준화되어 있다.
```

```markdown
// after
스타벅스 자료는 스타벅스가 채용을 목적으로 직접 작성·배포한 자사발행 콘텐츠(공식 역할 정의)로, 대형 프랜차이즈의 표준화된 업무를 보여주는 동시에 지원자를 유인하기 위해 매니저 역할을 실제보다 매력적으로(예: '사업 성장을 이끄는 리더') 서술했을 가능성이 있다. 따라서 소형 개인 카페와의 업무 표준화 차이뿐 아니라 자료 자체의 홍보적 성격도 감안해 해석해야 한다.
```

## 한계 — 50+재단 공고 고용형태 재확인 [org_culture_signal]

노원구·강북구 공고는 서울시 50+재단(www.50plus.or.kr)이 운영하는, 시니어 대상 채용 플랫폼에 게시된 공고다. 이것이 통상적 정규직 매니저 채용인지 시니어 사회공헌형·인턴형 일자리인지 본문에서 확인되지 않았는데, 고용 형태에 따라 채용·징계 권한, 발주 한도, 손익 책임 같은 실제 권한 범위가 크게 달라질 수 있다. '실제 업무 7가지' 표가 제시하는 '매장 전체를 맡는 매니저의 최대 책임 범위'가 이 두 공고와 동일한 직급을 전제하는지 원문에서 재확인해야 한다.

```markdown
// before
국내 근거는 공공 운영 카페 두 곳과 민간 공개 공고 한 곳에 불과하므로 민간 프랜차이즈나 개인 카페 전체를 대표하지 않는다.
```

```markdown
// after
국내 근거는 공공 운영 카페 두 곳과 민간 공개 공고 한 곳에 불과하므로 민간 프랜차이즈나 개인 카페 전체를 대표하지 않는다. 특히 노원구·강북구 공고는 서울시 50+재단이 운영하는 시니어 대상 채용 플랫폼에 게시된 것으로, 이것이 통상적인 정규직 매니저 채용인지 시니어 사회공헌형·인턴형 일자리인지가 본문에서 확인되지 않았다. 고용 형태에 따라 실제 권한 범위가 달라질 수 있으므로 두 공고의 고용 형태와 직급을 원문에서 재확인해야 한다.
```

## 성과를 볼 때 유용한 지표 — KPI 목록 출처 불명 명시 [financial_forensics]

바로 아래 나열된 재료원가율·폐기율·재고 차이·긴급 발주 횟수·인건비율·시간당 매출·체크리스트 준수율 같은 세부 KPI는 본문에서 인용한 BLS·O*NET·국내 채용공고·스타벅스 자료 어디에도 구체적 수치나 항목명으로 등장하지 않는다(단락 끝의 Tata Starbucks 인용은 '월간 보고·분기 사업 검토' 수준만 뒷받침한다). 표 형태로 제시되면 출처 기반 벤치마크처럼 읽히기 쉬우므로, 이 목록이 분석자가 종합한 권장안이고 실제 벤치마크 수치는 별도 확인이 필요하다는 점을 명시해야 한다.

```markdown
// before
아래는 특정 브랜드의 의무 기준이 아니라, 위 업무를 실제로 관리하기 위한 권장 점수판이다.
```

```markdown
// after
아래는 특정 브랜드의 의무 기준이 아니며, 인용된 BLS·O*NET·채용공고·스타벅스 자료 어디에도 재료원가율·폐기율·인건비율 등 구체적 목표 수치가 명시되어 있지 않다. 이 목록은 위 업무를 관리하기 위해 분석자가 종합한 권장 점수판이므로, 실제 업계 벤치마크 수치는 별도 재조사로 확인해야 한다.
```

## 결론 — 역할구조 수렴 주장 표본 재검증 [market_dynamics]

이 문서 전체 각주는 17개 번호가 매겨져 있지만 실제 URL은 7개뿐이다([1]=[6]=[14] BLS, [5]=[9]=[15] O*NET, [2]=[11] 노원구, [3]=[10]=[12] 강북구, [4]=[13] 민간공고, [7]=[16] 스타벅스, [8]=[17] Tata Starbucks). 즉 '서로 다른 자료'로 보이는 근거가 실제로는 소수 출처의 반복 재인용이고, 그마저 국가(미국 1건)·고용형태(국내 공공기관 시니어 공고 2건)·기업(대형 프랜차이즈 자사자료 2건)이 서로 다른 좁은 표본이다. '같은 역할 구조를 가리킨다'는 수렴 주장은 과장됐을 수 있으므로 추가 국내 사례(개인 카페·중소 프랜차이즈)로 재검증이 필요하다.

```markdown
// before
서로 다른 자료가 같은 역할 구조를 가리킨다.
```

```markdown
// after
서로 다른 자료가 같은 역할 구조를 가리키는 것으로 보이지만, 본문 각주 17개는 실제로 BLS·O*NET·노원구 공고·강북구 공고·민간 공고·스타벅스·Tata Starbucks라는 7개 고유 출처를 반복 재인용한 것이다. 표본이 좁고 국가·고용형태·기업 규모가 제각각이므로, 이 수렴 주장은 개인 카페·중소 프랜차이즈 사례를 추가 확보해 재검증해야 한다.
```
